# M10-5 の答えと解説

> 先に、自分の予想と観察を書き残してから読んでください。後片づけは、Cloudflare と GitHub の**実際の画面**を使います。2026-11-04 に、講師が、トークンの削除、Worker の削除、Secrets の削除を、実際に行いました（削除後の、Worker の URL が `404` になることと、Secrets の一覧が空になることを、確認済み。画面の名前は、変わることがあります）。

## 予想と結果

### ヒント

- 「公開」は、**インターネット**に対して。
- 使わない鍵が残っていると、**持ち主が忘れたまま、使える状態**が続く。

### 答え

| 問い | 答え |
|---|---|
| 公開前に確かめること | **公開される範囲**（誰が見られるか）、**返す内容**（個人情報・秘密がないか）、**秘密がコード・設定にないか**、**トークンの権限と範囲**、**テストが公開の前に通る設定か**、**戻し方の準備** |
| 片づけないと困ること | トークンが残り、**漏れたときに、使われる**。Worker が残り、**公開されたまま**（意図しない通信や、上限の消費）。Secrets が残り、**管理を忘れる** |

### チェックリストの見方

- **公開される範囲**: Worker の URL は、**誰でも**アクセスできる。**認証は、自分で作らない限り、ない**。
- **個人情報・秘密**: `index.ts` と `greeting.ts` が返すのは、挨拶と版だけ。`name` は、**エスケープ**されている（M9）。
- **`.gitignore`**: `.env*` と `.dev.vars*` が含まれていること。ローカルの秘密を、Git に入れない。
- **テストの順序**: `npm run check` が `Deploy Worker` より前にあること。

### 手順 4 の答え

- **トークンを残す危険**: 忘れたまま、**漏れても気づかない**。使われても、**誰も、気づかない**。
- **取り返しがつかなくなりやすいもの**: **公開される範囲**と、**個人情報・秘密の混入**。一度、公開すると、**他人にコピーされうる**（取り消せない）。トークンは、失効して作り直せる。
- **本番で追加で確かめること**: **個人情報の扱い**（M0 の方針）、**権限**（誰が公開・戻せるか）、**バックアップと復旧**、**ロールバックの準備**（データの形が変わるとき）、**監視と通知**。

## 振り返りの答え

- **3 つ**: 公開される範囲、秘密や個人情報が入っていないか、トークンの権限と範囲（ほか、テストが通る設定、戻し方）。
- **トークン**: 使い終わったら、**失効（削除）する**。必要なら、新しく作る。

## 補足

- 順序（トークン → Worker → Secrets）の理由: **力を持つものを、先に無効にする**。途中で作業を中断しても、**最も危険なものが、残らない**。
- リポジトリの削除は、**取り消せない**。**自分のリポジトリであること**を、確かめてから行う。
