# 演習 M10-5: 公開前の確認と、後片づけ

所要時間の目安: 20 分 / 対象: L1 / 前提: [演習 4](4-rollback.md)

## 目的

- 公開する前に、**何を確かめるか**の習慣をつける。
- 練習が終わったら、**トークンを失効し、練習用の環境を片づける**（本物の鍵を、放置しない）。

## 手順

### 0. 記録の Issue を作り、予想を書く（自分の力で）

[演習の進め方（M0 の 3b）](../../m0-orientation/README.md)に従い、「演習の記録」の Issue（演習: `M10-5`）を作ります。次の予想を、**実行する前に**書いてください。

1. 公開する前に、確かめるべきことを、**3 つ以上**挙げる。
2. 練習が終わったあと、**片づけないと、何が困るか**。

### 1. 公開前の確認（チェックリスト）

自分の `hello-worker-practice` について、次を、**1 つずつ、実際に確かめ**、結果を、記録の Issue のコメントに書きます。

| 確認すること | 確かめ方 | 結果 |
|---|---|---|
| **公開される範囲**: 誰が、アクセスできるか | Worker の URL は、**誰でも**アクセスできる。**シークレットウィンドウ**（ログインしていない状態）で、`/health` を開いて、見られることを確認する | |
| **返す内容に、個人情報・秘密が、ないか** | `src/index.ts` と `src/greeting.ts` を読む。返している文字を、すべて確認する | |
| **秘密が、コードや設定に、ないか** | `wrangler.jsonc`、`deploy.yml`、`src/` を読む。トークンやパスワードが、書かれていないか | |
| **秘密のファイルが、Git に入らない設定か** | `.gitignore` に、`.env` と `.dev.vars` が、含まれているか | |
| **トークンの権限と範囲** | Cloudflare の **Account API tokens**（トークンの一覧）で、`m10-practice-deploy` の行を開き、**画面を見るだけ**にする（保存・再発行はしない）。**権限**: 「Edit Cloudflare Workers」のテンプレートで入った権限（Workers Scripts など）が並んでいるか。**範囲**（Account Resources）: 自分のアカウント 1 つだけか | |
| **テストが、公開の前に、通る設定か** | `deploy.yml` で、`npm run check` が、`Deploy Worker` より**前**にあるか | |

### 2. 後片づけ

練習が終わったので、次を行います（**上から順に**）。

1. **API トークンを、削除（失効）する**: Cloudflare のダッシュボードの **Account API tokens** で、`m10-practice-deploy` の行の操作メニュー（「…」など）から、**Delete**（削除）を選ぶ。確認の表示を読んでから進め、削除後、一覧に `m10-practice-deploy` が**無い**ことを確かめる（画面の名前は、変わることがあります）。
   - **Roll**（値の再発行）は、削除ではありません。間違えて押さないこと。
2. **Worker を削除する**: ダッシュボードの **Workers & Pages** で、`hello-worker-practice` を開き、**Settings**（設定）のタブから、Worker の**削除**を選ぶ（Worker の名前の入力を求められることがあります）。削除後、Workers & Pages の一覧に `hello-worker-practice` が**無い**ことを確かめる。画面で、削除の項目が見つからないときは、`npx wrangler delete`（自分のアカウントへのログインが必要）を使う。
3. **GitHub の Secrets を削除する**: リポジトリの Settings → Secrets and variables → Actions で、`CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` を、削除する。
4. （任意）リポジトリは、**残しても、削除しても構いません**。削除は、**取り消せない**ので、**自分のリポジトリであること**を確かめてから行います。

### 3. 片づけの確認

- Worker の URL（`/health`）を開き、**もう、応答しない**（エラー、または、見つからない）こと。削除後は、`404` と、`error code: 1042` のような表示になります（講師の確認では、そうなりました。数字は、変わることがあります）。
- Cloudflare の、トークンの一覧に、練習用のトークンが**ない**こと。
- GitHub の Secrets の一覧が、**空**であること。

### 4. 考える

- トークンを、練習のあとも**残しておく**と、何が危険か。
- 公開前のチェックリストのうち、**いちばん、取り返しがつかなくなりやすい**のは、どれか。それは、なぜか。
- 本番のシステムで、公開前に、**追加で**確かめたいことは、何か。（個人情報、権限、バックアップ、ロールバックの準備など）

## 振り返り

- 公開前に確かめることを、**自分の言葉で**、3 つ説明できるか。
- 鍵（トークン）は、**使い終わったら、どうするか**。

答えは [answers/5-checklist-and-cleanup.md](../answers/5-checklist-and-cleanup.md)。見たあと、記録の Issue に「答えを見て気づいたこと」をコメントし、Issue を閉じます。
