# 演習 M2-1: 最初のセッション（読むだけ）

所要時間の目安: 25 分 / 前提: [README](../README.md) の導入（チャット画面が開き、自分のリポジトリのフォルダが作業フォルダになっていること）

## 目的

- AI エージェントを、**読むだけ**の状態で使ってみる。
- AI が実行しようとするコマンドの**確認画面を、1 つずつ読む**習慣をつける。
- AI への指示は、**チャット画面に、自分の言葉で書く**。

## 手順

### 0. 記録の Issue を作り、予想を書く（AI を使わずに）

[演習の進め方（M0 の 3b）](../../m0-orientation/README.md)に従い、「演習の記録」の Issue（演習: `M2-1`）を作ります。次の予想を、**AI を使う前に、自分の力で**書いてください。

- AI に「このファイルは何をしますか」と聞くと、AI は、ファイルを**変更する**か、**読むだけ**か。
- AI が「テストを実行したい」と言ったとき、確認の画面が出ると思うか。出るとしたら、何が書かれていると思うか。

### 1. 始める前の状態を確かめる

自分のターミナルで、次を実行します（これは、**あなた自身が**入力するコマンドです。`git status` は、[M1](../../m1-git-basics/README.md) で学んだ、変更の状況を調べるコマンドです）。

```bash
git status
```

変更が出ないことを確認します。**これが、片づけで戻す状態です。**

### 2. Plan モードで、チャット画面を開く

1. AI のチャット画面（デスクトップアプリ、または VS Code のパネル）を開き、作業フォルダが、自分のリポジトリになっていることを確認する。
2. プロンプト欄（入力欄）の近くの、**モードの選択欄（モード表示）**で、**Plan** を選ぶ。
3. **会話を始める前に、画面のモード表示が「Plan」になっていることを、自分の目で確かめる。**（使い方やバージョンによっては、最初のモードが Plan や Manual ではない場合があります）

### 3. 読むだけの質問をする

チャット欄に、次のように入力して送信します。

> 「`modules/m4-pr-and-ci/app/src/session-policy.ts` は、何をするファイルですか。プログラミングを知らない人にも分かるように、説明してください。まだ、何も変更しないでください。」

説明が出たら、読みます。**分からない言葉**に、印を付けておきます（演習 2 で使います）。

### 4. 確認画面を読む

チャット欄に、次のように入力して送信します。

> 「`modules/m4-pr-and-ci/app` の、テストを実行してください。」

AI が、コマンドの実行の許可を求める画面が出たら、**許可する前に**、次を記録の Issue のコメントに書いてください。

- 実行されようとしているコマンド（そのまま写す）
- そのコマンドが、**何をするか**を、自分の言葉で（分からなければ「分からない」と書き、チャットで「このコマンドは、何をするのですか」と聞く）
- そのコマンドは、「**読むだけ**」「**ファイルを変更する**」「**外部に何かを送る**」「**消す**」のうち、どれか
- 許可するか、しないか。その理由

理由に納得できたら、許可します。

### 5. 変更を頼んでみる（承認はしない）

チャット欄に、次のように入力して送信します。

> 「`session-policy.ts` の、コメントを英語に変更してください。」

Plan モードでは、変更は行われず、**計画**が示されます。計画を読み、「何が変わるか」を確認します。**計画は承認せず**（続けて計画する側を選ぶか、中断します）、ファイルが変更されないことを確かめます。

### 6. セッションを終える

チャットを閉じる（または、新しい会話に切り替える）。

### 7. 片づけの確認

自分のターミナルで、次を実行します。

```bash
git status
```

**何も表示されない**こと（手順 1 と同じ）。何かが表示された場合は、何が変わったかを調べ、記録の Issue に書いてください（どの操作で変わったのか、考えます）。

## 振り返り

- 確認画面を読むことは、なぜ大切か。
- 内容が分からないコマンドが出たとき、どうするか。
- Plan モードで、変更を頼んだとき、何が起きたか。

答えは [answers/1-first-session.md](../answers/1-first-session.md)。見たあと、記録の Issue に「答えを見て気づいたこと」をコメントし、Issue を閉じます。
