# 演習 M9-1: 誰でも追加できる穴

所要時間の目安: 20 分 / 前提: [README](../README.md) の準備（`npm run seed:users` まで）

## 目的

**画面にログインが無い（または、ボタンを隠してある）だけでは、守られていない**ことを、体験する。画面を使わずに、サーバーを直接呼んで、確かめる。

> コードは書きません。手順書のコマンドを、実行するだけです。

## 手順

作業は `modules/m7-local-env/app` の中で行います。

### 0. 記録の Issue を作り、予想を書く（自分の力で）

[演習の進め方（M0 の 3b）](../../m0-orientation/README.md)に従い、「演習の記録」の Issue（演習: `M9-1`）を作ります。次の予想を、**実行する前に**書いてください。

1. ログインのない画面（M8 までのサーバー）に対して、**画面を使わず**、コマンドで「メモを追加して」と送ると、追加されるか。
2. ログイン付きのサーバーに、**同じ操作**を送ると、どうなるか。
3. ログイン付きのサーバーでは、ログインしていないと、画面に「追加フォーム」が出ない。これで、守られていると言えるか。

### 1. 2 つのサーバーを起動する

ターミナルを **2 つ**開き、それぞれで、`modules/m7-local-env/app` に移動して、次を実行します（どちらも、起動したままにします）。

| ターミナル | コマンド | 場所 |
|---|---|---|
| 1 | `npm run dev` | http://127.0.0.1:3100（ログインなし） |
| 2 | `npm run dev:secure` | http://127.0.0.1:3101（ログイン付き） |

ブラウザで、それぞれの場所を開き、メモの一覧が表示されることを確認します。

### 2. ログインのない画面に、画面を使わずに追加する

**3 つ目のターミナル**で、次を実行します。

```bash
curl -i -X POST http://127.0.0.1:3100/notes -d "title=added-by-curl"
```

- **Windows の PowerShell では、`curl` ではなく `curl.exe` と入力**してください（`curl` は、別の機能の別名です）。Git Bash では、そのまま `curl` で動きます。
- **タイトルは、英数字**にしてください（日本語は、文字化けして保存されることがあります）。

結果の、最初の 1〜2 行（`HTTP/1.1 …` と `location: …`）を、記録の Issue のコメントに書き写します。そのあと、ブラウザで http://127.0.0.1:3100 を再読み込みし、`added-by-curl` が、一覧に増えたかを確認します。

### 3. ログイン付きのサーバーに、同じ操作を送る

```bash
curl -i -X POST http://127.0.0.1:3101/notes -d "title=added-by-curl-2"
```

結果の、最初の 1〜2 行を、記録に書き写します。ブラウザで http://127.0.0.1:3101 を再読み込みし、`added-by-curl-2` が増えたかも、確認します。

### 4. 画面を見る

ログインしていない状態で、http://127.0.0.1:3101 を見ます。**追加フォームは、出ていますか。**

### 5. 考える

- ログイン付きのサーバーで、追加できなかったのは、**画面にフォームが出ないから**か。それとも、**サーバーが断ったから**か。（手順 3 の結果から、考える）
- 「画面にボタンを出さなければ、操作されない」と言えないのは、なぜか。

### 6. 片づけ

- 2 つのサーバーを、それぞれのターミナルで、**Ctrl+C** で止めます。
- データベースを、初期状態に戻します。**テストユーザーも消える**ので、あとの演習のために、作り直します。

  ```bash
  npm run db:reset
  npm run seed:users
  ```

## 振り返り

- 画面は、誰のものか。利用者は、画面を使わずに、サーバーを呼べるか。
- 守りは、**どこで**行うべきか。

答えは [answers/1-open-api.md](../answers/1-open-api.md)。見たあと、記録の Issue に「答えを見て気づいたこと」をコメントし、Issue を閉じます。
