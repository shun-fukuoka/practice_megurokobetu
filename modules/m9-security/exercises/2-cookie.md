# 演習 M9-2: Cookie を見る

所要時間の目安: 25 分 / 前提: [演習 1](1-open-api.md)（片づけまで終えていること。テストユーザーがあること）

## 目的

- ログインすると、ブラウザに**何が保存される**かを、自分の目で見る。
- **HttpOnly の有無**で、JavaScript から見えるものが変わることを、確かめる。

> コードは書きません。ブラウザの開発者ツールで、見るだけです。画面の名前は、ブラウザや版で、少し違うことがあります。

## 手順

作業は `modules/m7-local-env/app` の中で行います。

### 0. 記録の Issue を作り、予想を書く（自分の力で）

[演習の進め方（M0 の 3b）](../../m0-orientation/README.md)に従い、「演習の記録」の Issue（演習: `M9-2`）を作ります。次の予想を、**実行する前に**書いてください。

1. ログインすると、ブラウザに、いくつの Cookie が保存されるか。
2. 開発者ツールの「コンソール」で `document.cookie` と入力すると、**ログインの Cookie は、見えるか**。
3. 「見えるもの」と「見えないもの」があるとしたら、何の違いか。

### 1. サーバーを起動する

```bash
npm run dev:secure
```

起動したままにします。ブラウザで http://127.0.0.1:3101 を開きます。

### 2. 開発者ツールを開く

F12 キーを押して、開発者ツールを開き、**Application**（アプリケーション）タブを選びます。左の一覧の **Cookies** の下にある、`http://127.0.0.1:3101` を選びます。

### 3. ログイン前の Cookie を見る

`lab_theme` という Cookie が、1 つだけあることを確認します（最初にページを開いたときに、サーバーが保存したものです）。次の列を、記録に書き写します。

- `HttpOnly` 列（チェックが付いているか）
- `SameSite` 列
- `Path` 列

### 4. ログインする

画面の「ログイン」を押し、`teacher@test.local` と `practice-pass-123` で、ログインします。開発者ツールの Cookie の一覧を見て、**増えた Cookie** を確認します。次の表を、記録に書き写します。

| Cookie の名前 | HttpOnly | SameSite | Path | 有効期限（Expires / Max-Age） |
|---|---|---|---|---|
| `lab_theme` | | | | |
| `lab_session` | | | | |

### 5. JavaScript から見えるものを確認する

開発者ツールの **Console**（コンソール）タブを開き、次を入力して、Enter を押します。

```js
document.cookie
```

表示された文字列を、記録に書き写します。**`lab_session` は、含まれていますか。`lab_theme` は、どうですか。**

> ブラウザによっては、コンソールへの貼り付けに、警告が出ます（「理解できないコードを貼り付けない」旨の警告）。これは、**ブラウザが、悪意のある人にだまされて貼り付けてしまう被害を、防ぐ**ための、保護の仕組みです。ここでは、手順書の短い 1 語を、**自分で入力**してください。

### 6. ログアウトする

画面の「ログアウト」を押し、Cookie の一覧を、もう一度見ます。`lab_session` は、どうなりましたか。

### 7. 考える

- `lab_session` が、`document.cookie` に**出てこない**のは、なぜか。
- もし、画面に悪意のあるスクリプトが実行されたとき（演習 4）、**HttpOnly の Cookie と、そうでない Cookie**で、何が違うか。
- `SameSite=Lax` は、何を防ぐ設定か。（README の表を見ながら、自分の言葉で）

### 8. 片づけ

サーバーを、**Ctrl+C** で止めます（データベースは、変更していません）。

## 振り返り

- Cookie とは何か。ログインの状態を、どうやって保っているか。
- なぜ、ログインの Cookie には、HttpOnly を付けるのか。
