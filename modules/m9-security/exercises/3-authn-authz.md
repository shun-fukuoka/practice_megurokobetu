# 演習 M9-3: 認証と認可

所要時間の目安: 30 分 / 前提: [演習 2](2-cookie.md)

## 目的

- **認証**（誰か）と**認可**（何をしてよいか）が、別であることを、体験する。
- **画面から送られる値は、信じてはいけない**ことを、確かめる。
- **Cookie を書き換えると、どうなるか**を、見る。

> コードは書きません。手順書の短い文を、コンソールに入力するだけです。

## 手順

作業は `modules/m7-local-env/app` の中で行います。

### 0. 記録の Issue を作り、予想を書く（自分の力で）

[演習の進め方（M0 の 3b）](../../m0-orientation/README.md)に従い、「演習の記録」の Issue（演習: `M9-3`）を作ります。次の予想を、**実行する前に**書いてください。

1. 生徒（`student@test.local`）でログインすると、画面に「追加フォーム」は、出るか。
2. 画面を使わず、コンソールから「メモを追加して」と送ると、生徒は、追加できるか。
3. 送る内容に「`role=teacher`（私は講師です）」と**書き足す**と、どうなるか。
4. ログインの Cookie の値を、**少し書き換える**と、どうなるか。

### 1. サーバーを起動する

```bash
npm run dev:secure
```

起動したままにします。ブラウザで http://127.0.0.1:3101 を開きます。

### 2. A: 生徒でログインする

`student@test.local` と `practice-pass-123` で、ログインします。画面に、何が表示されたか（追加フォームの有無、メッセージ）を、記録に書きます。**ログインは、できましたか。**

### 3. B: 画面を使わず、生徒として、追加を試みる

開発者ツールの **Console** タブで、次を入力して、Enter を押します（コンソールに貼り付けの警告が出たら、演習 2 の説明を読み、入力し直してください）。

```js
fetch("/notes", { method: "POST", headers: { "content-type": "application/x-www-form-urlencoded" }, body: "title=student-added" }).then((r) => console.log(r.status))
```

表示された数字（HTTP のステータス）を、記録に書きます。

### 4. C: 「私は講師です」と書き足して、送る

もう一度、コンソールで、次を入力します（`&role=teacher` が、増えています）。

```js
fetch("/notes", { method: "POST", headers: { "content-type": "application/x-www-form-urlencoded" }, body: "title=student-added&role=teacher" }).then((r) => console.log(r.status))
```

表示された数字を、記録に書きます。**役割を、偽装できましたか。**

### 5. D: 講師でログインし直す

画面の「ログアウト」を押し、`teacher@test.local` と `practice-pass-123` で、ログインします。**追加フォーム**が出ることを確認し、`teacher-added` というタイトルで、メモを追加します。一覧に増えたことを確認します。

### 6. E: Cookie を書き換える

講師でログインしたまま、開発者ツールの **Application** → **Cookies** → `http://127.0.0.1:3101` を開きます。

1. `lab_session` の「Value」の列を、**ダブルクリック**して、末尾の数文字を、別の文字に書き換えます（Enter で確定）。
2. ブラウザで、ページを**再読み込み**します。

画面は、どうなりましたか（ログイン中の表示、追加フォームの有無）。

### 7. 考える

- 手順 B・C の結果から、**サーバーは、何を根拠に**「この人は生徒だ」と判断しているか。フォームに書いた `role=teacher` は、なぜ効かなかったのか。
- 「ログインできた」ことと、「何でもできる」ことは、なぜ違うのか。**認証と認可**の言葉で、説明する。
- 手順 E で、Cookie を書き換えると、ログインが無効になった。それは、なぜか。（サーバーは、Cookie の中身を、どうやって確かめているか）

### 8. 片づけ

- サーバーを、**Ctrl+C** で止めます。
- 追加したメモを消すため、データベースを初期状態に戻し、テストユーザーを作り直します。

  ```bash
  npm run db:reset
  npm run seed:users
  ```

## 振り返り

- 認証と認可は、それぞれ、何を確かめているか。
- 画面の値を信じず、サーバーが確かめた情報を使うのは、なぜか。
